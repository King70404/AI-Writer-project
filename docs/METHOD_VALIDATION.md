# 写作方法验证与复用（F08）

当前代码位于 [PR #49](https://github.com/King70404/AI-Writer-project/pull/49)，合并和完整门禁状态见 [PLAN](../PLAN.md)。本页说明本分支行为，不表示 main 已交付。

## 作者操作

1. 在写作台的“准备”分区维护已确认规则，可填场景标签、适用条件、不适用条件和优先级。打开“写作方法验证与复用”，选择规则版本与方法；场景相关建议最多三项，作者仍可自己选择。
2. 手工标注先使用已保存正文，选择片段并填写“体现该方法 / 没体现 / 不适用”和理由。记录绑定正文修订与规则版本；后续改写不会重写旧判断。
3. 如需对照试写，先保存正文与章节规划并选择场景。准备时冻结正文、规划、场景、单条规则和模型快照；不调用模型。首版试写正文上限 50,000 字符，手工标注仍可使用更长的已保存正文。
4. 分别确认发送候选 A 和 B；同一试验两份按顺序发送，每份最多一次显式发送，不会失败后自动补发。两份使用相同来源，只有是否选用该规则不同；排列随机，评分前不揭示哪份使用规则。发送前显示保守预估、预算结果和发送模型；云模型另需作者确认。
5. 对焦点清晰度、行动连续性、对话潜台词、场景停留、原创表达各打 1–5 分并说明理由，保存后揭示方法。评分只记录本次作者偏好，不采用候选，不保证文学质量。
6. 个人模板由作者填写可迁移的方法字段，不默认复制范文、正文、角色名或情节。跨书使用前再次确认，复制为目标书的新规则版本并保留来源标识；删除模板不影响已复制版本。

## 数据与调用契约

- 用量操作为 `method_trial`，复用既有网关、发送前台账和预算。strict 拒绝时不发请求、不写用量；台账不可用时拒绝发送。费用沿用 B-3 的冻结价格，不回溯换算。
- A/B 的预估使用同一保守上限，避免从不同预估长度提前猜出排列。服务商 token 与本机估算分开显示。
- 候选只保存在方法试验中，不直接写正文、确认事实或发布规则；当前不提供自动优化、额外 AI 打分或自动重试。
- 重叠发送在服务端拒绝，不产生第二次调用或台账；进程重启后遗留发送记为失败；已完成结果与作者评分保留。规则更新不修改旧试验。来源变化时界面提示该记录使用冻结来源。
- 迁移链为 `0018` → `0019`（缓存价格）→ `0020`（方法记录及用量操作）。已有作者库必须先备份再显式升级，普通启动不自动迁移。开发只以隔离合成数据库验证旧台账、价格、预留和不可变触发器保留。

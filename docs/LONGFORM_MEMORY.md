# 长篇记忆与一致性评审

入口：小说 → 大纲与章节 → 写正文 → AI 协作写作 → 打开长篇记忆与评审。先保存正文，选择可用模型；旧库提示升级时，由作者明确点击“备份并启用 AI 协作”。

## 确认故事事实

可以手工填写事实标题、内容和逐字原文引文，保存为待确认事实。也可以准备本章评审，在查看实际发送正文和前文事实后确认发送，让模型提取候选事实。云模型需要本次发送同意；准备、刷新和打开页面均不会调用模型。

事实内容应写清人物、发生时点和适用范围，区分发生过的事件与仍持续的状态。伤势恢复等情节变化后，应核对旧状态是否继续适用。

提取结果需要先编辑并保存为候选，再明确确认。模型的概括可能有误，作者应核对引文是否真正支持这条事实。待确认、驳回和来源已变化的事实均不会进入后文章节的记忆。

修改已有事实会追加一个版本。若原章节正文或章节修订已改变，事实标记为需要复核；点击“编辑并核对原文”，用最新正文引文修正事实，再明确确认。旧版本保留，不覆盖历史。

## 跨章使用与评审改写

召回范围是同一小说、排在当前章之前、已经作者确认且来源修订仍有效的事实，最多24项、约10000字符；预览显示选中事实和省略数量。默认按照文字二元组关联程度及前文顺序选择（确定性）。

### 可选：语义召回（C-4）

作者可在模型配置中添加用途为“嵌入（语义索引）”的模型（沿用同样的服务地址规则与受保护 Key），并填写嵌入单价（每百万输入 token）。在“长篇记忆与评审”的“语义索引”中为本书选择该嵌入模型、打开“语义召回”。

- 索引对象：已确认且来源未变化的事实（标题与内容），以及各章已保存正文的分块（每块800字）；正文分块只用来表示“本章在写什么”，不会作为召回内容进入上下文。只保存向量和文本哈希，不另存正文。
- 建立与增量更新必须由作者手动触发：面板先显示待嵌入条目、请求数、输入 token 上限、预估费用及预算判定，作者勾选确认（云端模型另需同意发送）后才发送。每次建立/更新都按服务商价格计费，每个请求记为“建立语义索引（嵌入）”用量并受预算约束；严格预算拒绝时不发送。价格、内容或模型变化后原预估失效，需要重新查看。中途失败时已完成的批次保留，剩余部分不会自动重发。不在后台自动调用。
- 召回：启用且本章正文与全部候选事实都有有效索引时，按向量相似度与文字关联混合排序；作者固定/排除仍然优先，预算不变。召回只读取已保存的向量，不调用模型。本章正文修改、事实新增或修改、嵌入模型配置变更后，索引视为过期：召回回退为确定性文字关联，并在“本次依据”和召回预览中注明原因；增量更新只重新嵌入变化的条目。
- 语义召回同样不能保证找到所有相关事实，效果取决于所选嵌入模型。

准备续写或改写时，所选事实及其事实版本、原章节和原文修订进入冻结上下文。后续改动不会改变已经准备好的任务。可在发送内容中核对实际使用了哪些依据。

准备本章评审会保存当前正文末尾最多24000字符、召回事实及模型配置。召回遵循与续写/改写相同的本章召回设置：作者排除的事实不发送，作者固定的事实在预算内优先；固定事实失效或超出预算时拒绝准备评审，不会悄悄丢掉。评审快照记录所用设置版本、排序方式（文字关联/语义/已回退及原因）以及每项事实纳入或省略的原因，可在“查看评审实际发送内容”中核对。确认发送后才调用一次模型。评审解释必须引用当前正文原句，引用的事实编号必须来自实际提供的事实。若模型输出不完整、引文编造或引用无效，评审失败，不自动重试；每个评审最多3次明确调用。失败或断线后先刷新查看状态，服务重启后中断评审标为失败，不静默重发。

点击“按此建议准备改写”，会为仍匹配最新正文且位置唯一的引文准备既有改写任务。此时仍未生成。查看冻结上下文后确认生成，候选由作者明确采用。引文变化、出现多次、正文未保存或规划存在未保存修改时，应先处理这些状态，再继续。

## 修改前文后

刷新工作台会比较已记录的来源修订、事实状态和版本、章节先后关系。来源变化的事实退出新任务召回；依赖旧正文或旧事实的评审会标记需要复核，工作台列出对应章节并提供入口。历史评审可查看，不能直接用于新一轮改写。

变化检测针对已记录的事实和评审依赖，不代表能发现全书所有潜在影响。作者仍需检查未被记录的情节联系。每部小说最多保存2000条事实，每章最多100份评审；超过范围需要在后续规模评测中扩展，不能据此宣称百万字一致性已验证。

## 保存与兼容

本版新增数据库迁移 `0009_add_story_memory`；语义索引另需迁移 `0025_add_semantic_index`（同样经产品内显式备份后升级）。已有0006、0007或0008数据库经产品内显式备份验证后升级，保留原正文、历史、模型、任务、候选、范文、规则和规划。普通启动不自动升级。

记忆和评审均按不可变修订保存；过期版本更新返回冲突，页面保留草稿。已删除小说的记忆不可通过普通接口访问。测试只使用隔离数据与受控模型服务；软件行为通过不等于长篇文学质量或实际服务商费用已经验证。
